# Промпт: своя видеоплатформа для уроков (Cloudflare R2, бесплатно)

Kinescope и Cloudflare Stream платные. Этот промпт делает своё защищённое видео на R2:
адаптивное качество 1080/720/480, свой плеер, ссылка работает только у купившего.

```
Работай в папке проекта моей платформы курса (Cloudflare Worker + D1). Пиши по-русски, просто.

ЗАДАЧА: своя видеоплатформа вместо Kinescope/Stream — хранение в R2, адаптивное видео HLS и свой плеер.
Видео уроков лежат в папке [путь]. Названия уровней: [список].

1. Подготовка. Прочитай код воркера, кабинета и схему базы. Проверь ffmpeg и node.
   Вход: npx wrangler login (Allow нажму я). Сделай резервную копию папки.
2. R2. Создай бакет [course-videos] и привязку VIDEOS в wrangler.jsonc. Если нужно включить R2 или принять условия — остановись, сделаю сам.
3. Перекодирование. Каждое видео → HLS: 1080p ~4500k, 720p ~2500k, 480p ~1000k, H.264, AAC 128k,
   сегменты 6 сек, ключевой кадр каждые 2 сек, один master.m3u8 с относительными путями, постер poster.jpg.
   -preset veryfast, по одному видео, с прогрессом. Случайный id на видео, сопоставление в videos.json.
4. Загрузка в R2 с повторами при ошибке и пропуском уже залитого. Сверь число файлов.
5. Отдача через Worker: маршрут /v/<token>/<id>/<файл>. token = подпись HMAC (id, срок, telegram id)
   на секрете VIDEO_KEY (создай случайный и положи через wrangler secret put, значение не печатай).
   Срок 6 часов, иначе 403. Поддержка Range (206). Плейлисты no-store, сегменты private max-age=3600.
6. Плеер в кабинете: hls.js с cdnjs (точная версия), на iPhone — встроенный HLS.
   Кнопки: play, перемотка, −10/+10, скорость 1–2×, качество Авто/1080/720/480, полный экран,
   двойной тап ±10 сек, продолжение с места остановки, отчёт о прогрессе.
7. В админке — список видео из R2 и привязка к уровню.
8. Проверка: верный токен 200, неверный 403, Range 206; видео играет на телефоне 390 px.
Выкладка только после моего «да». Секреты не печатай. Ничего не покупай.
```

Итог у меня: 6,9 ГБ видео в R2, счёт Cloudflare — $0.
