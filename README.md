# Tripwire Starter — автопродажи недорогого продукта через Claude

Цель: чтобы вы придумали и запустили **свой** недорогой продукт (трипвайр) — в бизнесе или в экспертизе — и продавали его на автомате. Начните с `00-logika-tripvayra.md`.

Набор, по которому я (Асланбек Беделханов, @bedelkhanov) запустил курс «Монтаж через Claude» за 9 900 ₸:
сайт с таймером цены → Telegram-бот → оплата Kaspi → уроки открываются сами → реклама в Instagram →
Claude ведёт рекламу и считает деньги по каждому ролику.

Результат: 1,7 млн ₸ выручки за 19 дней (8–26 ноября 2026), 181 оплата, расход на рекламу $1 660.

Кода здесь нет: всё собирает Claude по промптам. Вы даёте ему ссылку на этот репозиторий,
и он строит такую же систему под ваш продукт.

## Как пользоваться

0. Придумайте свой трипвайр по `00-logika-tripvayra.md` и проверьте спрос за вечер (10–20 продаж).
1. Пройдите регистрации из `01-registracii.md` (30–60 минут).
2. Откройте Claude Code (терминал) или приложение Claude и отправьте:

```
Прочитай репозиторий github.com/bedelkhanov/tripwire-starter целиком.
Мой продукт: [что продаёте, цена, что внутри].
Собери мне такую же систему по файлу 02-prompt-platforma.md.
Перед началом задай мне вопросы, которых не хватает. Секреты и ключи в чат не печатай.
```

3. Видео уроков — по `03-prompt-video.md`.
4. Реклама и ежедневные отчёты — по `05-reklama.md`.
5. Тексты бота и дожимы — `06-tsepochki-bota.md`.
6. Все промпты одним списком — `07-prompty.md`.

## Важно

- Ключи и токены (бот, Kaspi, Meta) кладите только в секреты Cloudflare. Claude не должен печатать их в чат.
- Начинайте с $10 в день на ролик. Бюджет растёт на +20–25% раз в 48 часов, не быстрее.
- Это не обещание дохода: результат зависит от продукта, роликов и аудитории.
