# Главный промпт: платформа автопродаж на Cloudflare

Скопируйте в Claude Code (лучше) или в приложение Claude с подключённой папкой. Замените всё в [скобках].

```
Ты собираешь для меня систему автопродаж недорогого онлайн-продукта. Пиши по-русски, простыми словами.
Работай в папке [путь к папке проекта]. Всё держим на одном аккаунте Cloudflare.

ПРОДУКТ: [название], цена [9 900 ₸], полная цена без скидки [20 000 ₸].
Внутри: [3–4 урока по 5–15 минут + бонус]. Для кого: [аудитория]. Мой стиль и тексты бери с [мой сайт / Instagram].

ЧТО СОБРАТЬ
1. Сайт-лендинг на [поддомен]: заголовок с результатом, видео-презентация, мои работы с цифрами,
   цена со скидкой по личному таймеру 15 минут, потом полная цена. Кнопка «Купить» ведёт в Telegram-бота
   с меткой: откуда пришёл человек (utm_source, utm_campaign, utm_content = название ролика).
   Вариации первого экрана под сегменты через ?a=[smb|expert|...].
2. Telegram-бот: /start с меткой, приветствие, кнопка оплаты. Заказ создаётся в момент нажатия.
3. Оплата Kaspi: [свой кассир Kaspi Pay / платёжный сервис]. Проверка оплаты раз в минуту и по вебхуку.
   После оплаты — доступ сразу, сообщение «Оплата прошла» и кнопка «Смотреть урок».
4. Уроки в Telegram Mini App и в браузере: вход только с Telegram-аккаунта покупателя
   (initData Telegram или одноразовая ссылка от бота). Прогресс, открытие следующего урока, домашка.
5. Админка на [admin-поддомен] с входом через Google только для моей почты: выручка по дням, воронка
   (зашли → бот → «Купить» → оплатили), источники и ролики, заказы, сообщения людей, рассылка, цепочки.
6. Аналитика: Meta Pixel + Conversions API с сервера (PageView, ViewContent, InitiateCheckout, Lead,
   AddPaymentInfo, Purchase). Покупка считается рекламой только при utm_source=meta.
7. Цепочки бота: напоминание тем, кто нажал «Оплатить» и не оплатил; «скидка сгорела — верни, пригласив друга»;
   подарок; бесплатный первый урок. Не чаще 1 сообщения в 6 часов, с 10:00 до 21:00.

ТЕХНИКА
- Cloudflare Worker (сайт, бот, API, админка), D1 (база), R2 (видео и файлы), cron-триггеры.
- Структура базы — как в 04-schema.sql из github.com/bedelkhanov/tripwire-starter.
- Секреты (токен бота, ключи оплаты, маркер Meta) — только через wrangler secret put. Сам их не печатай и не пиши в файлы:
  подготовь команду, значение вставлю я.

ПОРЯДОК
1. Сначала задай мне вопросы, которых не хватает, и покажи план одним экраном.
2. Собери и проверь локально (wrangler dev) с тестовой базой.
3. Проверь весь путь: заход по ссылке с меткой → бот → тестовая оплата 100 ₸ → доступ → урок открылся → событие Purchase в Meta.
4. Выкладывай только после моего «да». Выкладку и правки делай ночью.
5. В конце — короткий отчёт: ссылки, что проверить мне руками, что осталось.

НЕЛЬЗЯ: покупать, менять тарифы, принимать условия сервисов за меня, удалять мои данные.
```

## Что вы получите

- Сайт с таймером и кнопкой в бота
- Бота, который сам принимает оплату и выдаёт доступ
- Кабинет с уроками без логинов и паролей
- Админку с деньгами по каждому рекламному ролику
- Бесплатный хостинг: Workers, D1 и R2 укладываются в бесплатные лимиты на старте
